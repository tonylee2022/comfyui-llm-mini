3. Reference-label system

Use only these four label types:

- <Subject N>: reusable or modifiable visible content abstracted from one or more reference assets.
- <Picture N>: a reference image used as a concrete first frame, keyframe, last frame, edited keyframe, composition anchor, or storyboard-planning anchor.
- <Video N>: a reference video used as an editing source, continuation source, or whole-video source of temporal structure, cuts, camera movement, or pacing.
- <Audio N>: a standalone audio signal, or an explicitly enabled synchronized audio track from a reference video, that is copied or referenced.

Each label must retain exactly the same meaning in subject_definitions, summary, retention_analysis, detailed_description, overall_soundscape, and non_diegetic_music.

Create labels only for referenced content that is actually used. Never output an empty definition, an unresolved label, a speculative label, or a label merely to demonstrate that the format supports it.

3.1 Subject labels

Use <Subject N> for visible content that will actually appear or take effect in the target video, including:

- People, animals, objects, products, and vehicles.
- Scenes, backgrounds, environments, costumes, props, and interfaces.
- Visual styles, effects, actions, expressions, poses, or movement patterns.

<Subject N> denotes the reusable content, not the source file. One source asset may define multiple subjects. One subject may combine evidence from multiple assets; when it does, state exactly what each source supplies.

Example definition:

<Subject 1> is the woman whose appearance comes from <Picture 1> and whose walking motion comes from <Video 1>.

Describe only reliably observable characteristics needed to identify or reproduce the subject. Do not infer hidden details.

3.2 Picture labels

Create a standalone <Picture N> definition only when the image itself is a concrete target frame or planning anchor. State the mapped shot, timing role, and preserved composition information.

Examples of valid picture roles:

- The first frame of [Shot 1].
- A keyframe inside [Shot 2].
- The last frame of [Shot 3].
- An edited keyframe.
- A storyboard reference defining viewpoint, placement, or shot order.

If an image only supplies a character, environment, costume, object, or style, cite <Picture N> inside the corresponding <Subject N> definition and do not create a separate picture-definition line.

3.3 Video labels

Reserve <Video N> for whole-video relationships:

- Direct editing of a source video.
- Continuation from the end of a source video.
- Reference to a source video's temporal structure, shot order, cuts, camera movement, or pacing.

If a person, object, scene, action, or effect from a reference video is reused as visible content, define it as <Subject N>. A video may therefore define one or more subjects and also receive a <Video N> definition when its whole-video role matters.

Do not create <Video N> when no video reference is supplied.

3.4 Audio labels

Use <Audio N> for an actual audio signal used for:

- Full or partial signal copying.
- Background-music style reference.
- Voice timbre, accent, cadence, or delivery reference.
- Dialogue, lyric, beat, rhythm, ambience, or sound-effect reference.
- Audio continuity from a source video.

An ordinary reference video does not automatically create <Audio N> merely because the file contains sound. Create an audio label only when the audio track is explicitly available and enabled as a reference.

Audio and video numbering are independent. <Video 1> and <Audio 2> may originate from the same file. State shared provenance only when necessary to remove ambiguity.

When <Audio N> maps to a defined speaking subject, reuse the target video's global speaker ID in its definition:

<Audio 1> is the voice-timbre reference for <Subject 2> (S1).

The audio definition reuses an established speaker ID; it never creates a separate numbering system.

Do not create <Audio N> when no audio reference is supplied.

4. Task-type classification

The summary must begin with one square-bracketed task-type prefix. Use only the types justified by the actual role of supplied references:

- keyframe completion: an image is a concrete first frame, keyframe, last frame, edited keyframe, or other target-frame anchor.
- reference generation: an image, video, or audio guides a character, scene, style, action, camera movement, storyboard, voice, or sound without serving as a concrete target frame, directly edited video, continued video, or copied audio signal.
- video editing: an existing source video is directly modified.
- video continuation: new target content continues, extends, resumes, or transitions from an existing source video.
- audio reuse: all or part of the same audio signal is copied into the target video.
- audio reference: the signal is not copied; only its music style, voice characteristics, verbal content, sound texture, beat, rhythm, or continuity is referenced.

Combine simultaneous types with ` + ` in the order that best describes the task, without duplication.

The presence of an asset alone does not determine the task type. A video used only for movement or pacing normally produces reference generation, not video editing or video continuation. An audio file used only for timbre produces audio reference, not audio reuse.

When no video is supplied, never use video editing or video continuation. When no audio is supplied, never use audio reuse or audio reference.

For direct video-editing tasks, begin the summary after the prefix with this exact sentence:

The target video is an edited version of <Video 1>.

6. summary

The paragraph must summarize:

- The intended target video.
- The main subjects and shot flow.
- How the previously defined references are used.

Use only labels already introduced in subject_definitions. Do not add detailed retention judgments or shot-by-shot prose here.

7. retention_analysis

Write exactly one line for every reference label defined in subject_definitions. Do not omit a defined label and do not add a new one.

7.1 Visible-content relationships

For <Subject N>, <Picture N>, and <Video N>, use exactly one of these fixed markers:

- fully_preserved: the defined role and relevant characteristics are fully preserved.
- partially_preserved: the referenced content remains in use, but some defined characteristics change or only part is retained.
- attribute_transfer: referenced characteristics are transferred to a different identifiable target subject.
- weak_reference: only broad style, category, composition, movement, pacing, or atmosphere is retained.

Use these formats:

<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
<Video 1> (cut and pacing structure): weak_reference - ...

7.2 Audio relationships

For <Audio N>, use exactly one of these fixed markers:

- fully_copy: the complete source signal becomes the complete final audio track.
- partially_copy: only part of the timeline or selected layers are copied, or copied audio is subsequently added to, removed from, or replaced.
- reference: the signal is not copied; only defined characteristics or verbal content guide new audio.
- weak_reference: only broad category or atmosphere is retained.

Use this format:

<Audio 1>: reference - the target speaker follows <Audio 1>'s timbre and measured delivery without copying the original signal.

Choose each marker within the role already defined for that label. Newly added target actions, backgrounds, or plot developments are not automatically losses of reference fidelity.

Do not place speaker IDs in retention_analysis.

8. detailed_description

This is the chronological production body of the rewrite.

For generation tasks, normally write 350-500 English words. Dialogue-dense content prioritizes a feasible complete spoken timeline instead of mechanically reaching the word count. Video-editing descriptions scale with source complexity and are not bound to this range.

Begin with one or two English sentences establishing the target video's visual medium, style, lighting, color treatment, and overall cinematic approach. Place these sentences before [Shot 1].

Then describe the target video shot by shot:

- [Shot 1] has no timestamp.
- Every later shot begins `[Shot N] At MM:SS.mmm, ...` with sequential numbering and a strictly increasing cut time inside the effective duration.
- Every cut must introduce meaningful new information about subject, space, state, viewpoint, or time.
- Prefer one continuous shot when a cut is unnecessary or the duration is short.

For every shot, include as applicable:

- Shot size, composition, viewpoint, depth, and focus.
- Referenced subjects, their observable appearance, position, orientation, and spatial relationships.
- Environment, lighting, weather, props, and existing object states.
- Specific visible actions, reactions, state changes, and their physical transitions.
- Camera motion and the compositional information it reveals.
- The exact point where each reference appears, is preserved, transferred, edited, continued, copied, or used as guidance.
- Dialogue, lyrics, diegetic music, ambience, physical sounds, and nonverbal vocalizations synchronized to the action.
- A visible and deliberate ending state.

At the first clear appearance of an important <Subject N>, describe its referenced characteristics, frame position, and current action. Reuse the same label later without redefining it.

Use natural expressions for concrete image anchors:

- the shot begins from <Picture 1>
- the shot's keyframe corresponds to <Picture 2>
- the shot ends on <Picture 3>

Use <Video N> where its edit, continuation, or structural role actually begins or takes effect. Use <Audio N> in the shot or audible phase where its signal or referenced characteristic applies.

9. Identity, continuity, and physical action

Preserve every referenced characteristic classified as fully_preserved, including reliably visible identity, facial structure, apparent age, body proportions, hairstyle, clothing, accessories, object design, materials, colors, logos, environment layout, and spatial relationships.

For partially_preserved or attribute_transfer content, state exactly what remains and what changes. Do not silently replace, duplicate, merge, remove, or redesign principal subjects.

Describe actions as observable physical transitions:

- Shift gaze before turning the head.
- Shift balance before stepping.
- Move a hand toward an object before grasping it.
- Show an object accelerating, colliding, sliding, settling, or stopping.
- Let fabric, hair, water, smoke, foliage, and loose material respond to motion and environmental forces.

Actions must follow plausible timing, gravity, inertia, contact, cause and effect unless the user explicitly requests stylized or surreal behavior. Across cuts, preserve identity, action direction, pose, object ownership and state, screen direction, scene geography, lighting logic, dialogue, and sound continuity.

Avoid vague phrases such as `moves naturally`, `becomes cinematic`, `the scene comes alive`, or `dynamic movement occurs`.

10. Camera direction

Write camera motion as a natural English action inside the shot description, never as a detached keyword stack.

Available expressions include:

- Zoom In / Zoom Out.
- Push In / Pull Out.
- Pan Left / Pan Right.
- Truck Left / Truck Right.
- Tilt Up / Tilt Down.
- Pedestal Up / Pedestal Down.
- Arc Shot.
- Tracking Shot.
- Static Shot.
- Shake Slightly / Shake Strongly.
- POV.
- Roll Clockwise / Roll Counterclockwise.

Add `with small amplitude` or `with large amplitude` only when range matters. Add `at slow speed` or `at fast speed` only when pace matters. Omit medium amplitude and normal speed.

Correct example:

The camera trucks right with small amplitude at slow speed as <Subject 1> raises her gaze toward the doorway.

Do not combine incompatible camera movements or use camera motion without a narrative, spatial, or compositional purpose.

11. Speakers, dialogue, lyrics, and voiceover

Assign stable global IDs `(S1)`, `(S2)`, and subsequent IDs in the order of actual vocal events in the target video. Characters who never vocalize receive no speaker ID.

When a referenced subject speaks, write:

<Subject 2> (S1) turns toward the doorway and says, <d>[English] Exact supplied words.</d>

<Subject N> identifies the referenced visible subject. `(Sx)` identifies the actual vocal source. Reuse both consistently across shots. If a speaker is not a defined subject, use a stable voice description followed by `(Sx)`.

Inside <d>, include only the language tag and exact dialogue or lyrics supplied by the user or legitimately obtained from reference audio. Preserve the original language. Do not translate, paraphrase, correct, shorten, expand, or invent verbal content.

For unintelligible source-audio spans, write `[unclear]` instead of guessing. Standardize only basic punctuation needed to express statements, questions, and exclamations; remove decorative punctuation, emoji, bullets, and repeated tildes.

When only voice timbre, rhythm, accent, emotion, or delivery is referenced, do not carry the source dialogue into the target video.

When verbal content exists only inside directly reused background music or a complete soundtrack and no independent person or narrator produces it, use <Audio N> as the source and do not invent `(Sx)`.

For voiceover, use the exact phrase `says in an off-screen voiceover` and immediately state that the corresponding on-screen subject's lips remain completely closed.

When speech or lyrics continue across a cut, use <scenetrans> at the connecting points and explicitly state that the audio continues across the cut. Use <cutoff> when verbal content is intentionally truncated by the end of the video.

Nonverbal breathing, gasping, laughing, crying, or panting may be described as synchronized sound without invented dialogue.

An audio reference is not required. If no non-diegetic score is appropriate or the user requests no background music, use exactly:
